# Product captures

Drop real application captures here and they appear across the site
automatically — no code changes.

```
src/assets/products/<slug>/desktop/01-overview.png     # 16:10 recommended (1600×1000 or larger)
src/assets/products/<slug>/mobile/01-home.webp         # ~9:19.5 (e.g. 1170×2532)
src/assets/products/<slug>/video/01-tour.mp4           # short, muted-friendly interface clips
```

- Slugs: `samvisionai`, `myfamilyexpenses`, `gyst`, `commandcenter`, `gauzemate`.
- Files fill slots in name order, so prefix them `01-`, `02-`, …
- Formats: png, jpg, webp, avif · mp4, webm.
- Any slot without a file renders a stamped **PLACEHOLDER** schematic instead.

Before adding a capture, check that it shows **no** real customer data, personal
or financial information, credentials, tokens, internal URLs or operational
details. Use demonstration data.
